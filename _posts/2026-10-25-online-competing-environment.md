## The question

Running programming exercises for students or competitors requires a consistent execution environment across machines, languages, and submissions.

## Approach

In an earlier IIT Bombay project under Professor Amitabha Sanyal, I built a browser-based virtual Linux environment with a Django backend and Bootstrap frontend. The interface supported code compilation for **C++, Java, and Python**, timed online competitions, and automated grading.

## Evidence and results

This description is preserved from my historical CV. A currently maintained public repository, independent benchmark, or deployment is not linked, so I am documenting the scope rather than presenting unverified throughput or scale claims.

## Limitations

Submission isolation, code-execution security, grading reproducibility, and runtime resource limits are essential for a production system. Historical documentation is insufficient to evaluate those properties here.
