# vedant2100.github.io

Personal site of Vedant Borkute: https://vedant2100.github.io

Built with Jekyll on GitHub Pages, starting from the AcademicPages template (MIT licence, see `LICENSE`). Design notes are in `DESIGN.md`.

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Layout

- `_pages/about.md` is the homepage; `_pages/timeline.md` is the timeline.
- `_posts/` holds blog posts.
- `files/` holds the CV PDF.
- `fleet-mem/`, `replaygate/`, `skillfalsifier/`, `trajectory-safety-eval/` and `cs217-videos/` are standalone pages with their own styles.
