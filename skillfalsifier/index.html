About the real experiment

The public Python project runs an LLM-powered skill generator, compares baselines, evaluates candidates on training, held-out, and adversarial examples, and applies these two promotion rules. This webpage only reproduces the decision logic. It does not run a model, simulate experiment scores, or claim that the example numbers were measured.
